# Anonymous review release

This package omits first-party contributor identities, personal emails, affiliations, personal repository links, account/session metadata and Git history. It contains code, synthetic tests and label-only numerical observations. It excludes source poems, raw prompts/responses/events, credentials, theory text/PDFs and manuscript files.

Scientific attribution remains in third person: Chatzikyriakidis and Natsina (2026), the Greek_Rhyme repository, and Topintzi, Avdelidis and Valkanou (2019) are cited as prior work. Those references do not assert any authorship overlap. Removing source attribution would impede reconstruction and scholarly credit. The project-level copyright notice is retained; it names no individual.

The scoring code, other included study source and all released result records are unchanged. Freeze metadata copies omit precise workflow timestamps, private review-log locations and the compiler build string, and are explicitly marked as derivatives. Their retained historical hashes refer to original artifacts, not to anonymized copies. `provenance/source_records.json` distinguishes those relationships; `provenance/public_manifest.json` hashes the actual release bytes. Tests and public numerical replay remain runnable without the omitted inputs.

This is an identity-redacted distribution, not a guarantee of unlinkability: distinctive scientific results, code, source citations or matching content elsewhere can permit association. It does not certify compliance with a venue's review policy. A review link should expose only this sanitized snapshot, without commit history or contributor profiles.

The extension follows the same identity policy: byte-identical original scoring/runner/preparation code and label-only study records, derivative design metadata without precise workflow timestamps, and no raw study inputs/outputs, account metadata or private paths. The separate diagnostic releases newly constructed artificial inputs and a request specification, without raw HTTP or remote generation IDs. Matching code/results and historical hashes can still permit association with other public copies.
